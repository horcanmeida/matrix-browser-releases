矩阵浏览器 · 安装与激活

适用：Mac Apple Silicon（M 系列）与 Windows x64。此为内测软件，请先阅读本版本说明。

当前 Mac 包只有临时签名，尚未经过 Apple 公证；Windows 包尚未签名，因此可能出现开发者身份或信誉提示。来源和 SHA256 完整性校验不代表平台签名认证。若提示恶意软件、文件损坏或设备管理策略禁止，请停止并联系支持，不关闭系统保护。

1. 下载正确安装包

在软件“我的 → 关于与更新”点击检查更新，查看版本说明，再点击下载。软件显示进度并核对 SHA256；完成后点击“在文件夹中显示”。安装包下载不要求访问私有代码仓库，也不要求 GitHub 账号。

Mac 选择名称含 mac-arm64.dmg 的文件；Windows 选择 win-x64-setup.exe。当前没有 Intel Mac、Windows ARM 原生包。请勿把电脑上的账号资料、会话或授权目录随安装包发给其他人。

2. Mac 安装或更新

  1. 已有版本先在软件中完成本机资料备份，等待备份完成，再正常退出旧版。安装和备份是两个独立步骤。
  2. 打开 DMG，将“矩阵浏览器”拖入 Applications（应用程序）；更新时选择替换原应用。
  3. 从应用程序打开。如果仅提示无法确认开发者或未公证，请先核对来源，再按系统提供的单个应用确认流程操作：系统设置 → 隐私与安全性 → 安全性 → 仍要打开。仅在系统确实提供此按钮时，由你本人确认。
  4. 若系统不提供确认选项，或提示软件会损坏电脑，请停止并联系支持。不要运行去除隔离标记、关闭 Gatekeeper 或禁用安全检查的命令。

以 Apple 官方安全打开应用说明和当前系统提示为准。

3. Windows 安装或更新

  1. 先备份本机资料并退出旧版。双击 setup.exe，沿用原安装目录完成覆盖安装。
  2. 未签名软件可能显示“Windows 已保护你的电脑”或“未知发布者”。请核对文件来源、名称和完整性后再决定是否继续。若系统仅为信誉提示并提供“更多信息 → 仍要运行”，由你本人逐项确认。
  3. Smart App Control、组织管理策略或杀毒软件可能直接阻止运行。没有继续选项时，请停止并联系支持；不关闭 Defender、SmartScreen 或组织安全策略。

参见 Microsoft 对应用信誉与未签名包的说明。

4. 首次申请并激活

  1. 在实际使用的电脑和系统用户下打开软件，进入“我的 → 授权管理”。
  2. 点击“复制设备授权申请”，把复制出的 JSON 文本发送给授权联系人。申请仅包含产品和设备专用哈希，不需要密码、Cookie、原始硬件编号或账号资料。
  3. 收到签名授权文件后，点击“导入授权文件”，选择收到的 .txt 文件；也可在高级选项粘贴完整授权码。
  4. 看到激活成功后，核对授权概览中的有效期和已启用能力，再自行继续原操作。每台电脑、每个系统用户分别申请，其他设备的授权文件不能通用。

有效期按签发时约定执行；本轮 7 天内测从签发时起计算，并非从首次打开或激活时起计算。到期或更换设备请联系签发人；正常同机更新不需要清空授权或重复申请。不要删除资料目录来“修复”激活。

更新沿用原 hongguan-workbench 资料目录与 cn.horcan.workbench 产品身份，保留账号、会话、素材、记录和授权。不要先卸载并删除数据，不要让新旧版本同时运行，也不要手动覆盖活动中的数据库。

升级后如需回退，先备份当前资料，再联系支持使用匹配版本的完整备份恢复。旧版可能只能只读新版资料，不能单靠重新安装旧版来回退数据。
